# 《精英军团》— 红警题材战棋卡牌“开格子”即时对抗小游戏

基于 **Phaser 3 WebGL 游戏引擎 + TypeScript + Vite** 打造的移动端竖屏红警战棋卡牌策略对抗游戏，完整还原《精英军团》核心“开格子抢矿 → 暴兵自动交战 → 兵种克制博弈 → 摧毁敌方基地”玩法与局外养成体系。

---

## 核心玩法与特色

### 1. 局内“开格子”即时战略对抗（PvP 排位模式 & 双基地合作模式）
- **对称六边形海岛战场（开局 93格 vs 93格）**：平顶六边形（Flat-Top Hex）草地与沙漠阵营领地，部队行军经过之处自动染成己方领地颜色，上方实时显示双方格数压制条。
- **确定性蓝标开格子（告别纯随机空地挫败感）**：
  - 围绕己方已建建筑的相邻地块自动生成可解锁的蓝色水滴建造图标与金币价格。
  - **闪烁彩色宝石圈矿脉格**必出 **【钻井金矿】**，持续高速产出金币并弹出 `+4.3` 产金跳字。
  - **动态相连要塞石墙**：每扩建一格建筑，外围混凝土地堡围墙自动向新地块外沿无缝延伸合并；建筑被摧毁时留下冒烟废墟并重算防线。
- **局内三大战术主动交互**：
  - **🛠️ 科技强化**：消耗 `30 → 50 → 75...` 金币升级局内科技等级，永久提升本局全军攻击力与攻速。
  - **🪂 召唤伞兵**：冷却就绪后点击地图任意陆地格（或双击按钮自动奇袭敌后金矿），运输机掠空投下 **5 名精锐空降兵（突击大兵 + 重机枪兵）** 乘降落伞突袭！右上角同步显示敌军伞兵空投倒计时预警。
  - **⚡ 指挥官专属大招**：
    - **麦克将军【狂暴集结】**：全军攻速 +42%、移速 +35%
    - **鲍里斯元帅【基洛夫空袭】**：高爆航弹覆盖敌军最密集集群
    - **铁壁·娜塔莎【铁幕护盾】**：全军披上红警铁幕免伤 70% 并紧急维修

### 3. 完整局外养成与移动端操作体验
- **五大功能页签**：`商店（每日补给与五连抽卡包）`、`部队（5套预设卡组编成、卡牌升级提升全军战力%）`、`对战（雪山哨塔微缩景观岛、对战模式、合作模式、4槽宝箱开启）`、`指挥官`、`克制图鉴`。
- **丝滑手势与镜头系统**：支持单指拖拽平移战场、双指捏合缩放 / 滚轮滚动、右侧实时小地图点选跳转，以及 **🔭敌情 / ⚔️前线 / 🏠基地 / 🗺️全景** 一键镜头切换。
